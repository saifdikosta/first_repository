# Recovery Assistant

A mobile app designed to help users overcome addiction through regular motivational notifications, progress tracking, and helpful resources.

## Features

- **Customizable Notification System**: Set up regular motivational messages based on addiction type
- **Progress Tracking**: Monitor days clean and achievements
- **Resource Hub**: Access to helpful articles, videos, and community support
- **Privacy-Focused**: Your recovery journey stays private and secure

## Tech Stack

- React Native / Expo
- TypeScript
- Expo Notifications
- Expo Task Manager

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- EAS CLI (`npm install -g eas-cli`)

### Installation

1. Clone this repository
   ```
   git clone https://github.com/yourusername/recovery-assistant.git
   cd recovery-assistant
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the development server
   ```
   npm run dev
   ```

### Building the App

To create an APK for Android:

```
npm run build:android
```

This will guide you through the process of building an APK using EAS Build.
