# Recovery Assistant - Download Instructions

Thank you for your interest in the Recovery Assistant app! Follow these steps to download and install the app on your mobile device.

## Android Installation

### Option 1: Download the APK directly

1. Visit our download page at: [https://expo.dev/artifacts/latest](https://expo.dev/artifacts/latest)
2. You'll need to log in with the Expo account that built the app
3. Download the latest APK file
4. On your Android device, you may need to enable "Install from Unknown Sources" in your settings:
   - Go to Settings > Security (or Privacy)
   - Enable "Install from Unknown Sources" or "Install Unknown Apps"
5. Open the downloaded APK file on your device to install

### Option 2: Using Expo Go (for testing)

1. Install the Expo Go app from the [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)
2. Open the camera app on your device
3. Scan this QR code (or the one provided by the developer):
   [QR code placeholder]
4. The Recovery Assistant app will open in Expo Go

## iOS Installation

Currently, the app is available through TestFlight for iOS users.

1. Request an invitation from the developer
2. You'll receive an email with a TestFlight invitation
3. Install TestFlight from the [App Store](https://apps.apple.com/us/app/testflight/id899247664)
4. Open the invitation email on your iOS device
5. Follow the instructions to install the app through TestFlight

## Troubleshooting

If you encounter any issues during installation:

### Android

- Make sure "Install from Unknown Sources" is enabled
- Check that you have enough storage space on your device
- If you get a "Parse Error", try downloading the APK again
- Ensure your Android version is 5.0 or higher

### iOS

- Make sure you're opening the TestFlight invitation on the iOS device where you want to install the app
- If the invitation has expired, contact the developer for a new one
- Ensure your iOS version is 12.0 or higher
